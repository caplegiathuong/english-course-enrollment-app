## 1. Project Overview

This project is a UX design concept for a mobile application that helps university students and young adults discover English communication courses and complete the enrollment process.

The app focuses on making course discovery and registration simple, clear, and accessible.

## 2. Target Audience

- University students
- Young adults
- English learners who want to improve their communication skills

## 3. Project Goals

- Make English courses easier to discover.
- Present course information in a clear structure.
- Help users learn about teachers and their experience.
- Simplify the course enrollment process.

## 4. UX Design Process

The project follows the UX design process covered in the Google UX Design Certificate:

1. UX Research
2. Competitive Audit
3. User Persona
4. User Journey Map
5. Information Architecture
6. Sitemap
7. User Flow
8. Storyboarding
9. Paper Wireframes
10. Digital Wireframes
11. Low-Fidelity Prototyping
12. Simulated Usability Study

## 5. Key Features

- Browse available English courses.
- View course descriptions and learning outcomes.
- Explore schedules and tuition information.
- View teacher profiles and experience.
- Submit an enrollment form.
- Receive enrollment confirmation.
